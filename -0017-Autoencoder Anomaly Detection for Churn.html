Autoencoder Anomaly Detection for Churn

Method: An Autoencoder is an unsupervised neural network trained to compress data (Encoder) and then reconstruct it (Decoder). It is trained only on 'normal' (retained) student data. When a high-risk (churning) student's unusual profile is fed in, the network struggles to reconstruct it, resulting in a high **Reconstruction Error**, which is a powerful anomaly signal.
